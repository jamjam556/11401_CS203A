# Section A understand and clearly define:

**1. General Tree**
A **General Tree** is a non-linear data structure consisting of nodes organized in a hierarchical manner.Each node can have zero or multiple child nodes. [cite_start]There is **no limit** on the number of children a node can possess[cite: 19].

**2. Binary Tree**
[cite_start]A **Binary Tree** is a tree structure where each node is restricted to having **at most two children**[cite: 21].

**3. Complete Binary Tree**
A **Complete Binary Tree** is a binary tree in which every level, except possibly the last, is completely filled. [cite_start]On the last level, all nodes are filled from **left to right** without any gaps[cite: 23].

**4. Binary Search Tree (BST)**
A **Binary Search Tree (BST)** is a binary tree that [cite_start]The values in its **left** subtree are strictly **less than** the node's value, and the values in its **right** subtree are strictly **greater than** the node's value[cite: 25].

**5. AVL Tree**
An **AVL Tree** is a **self-balancing** Binary Search Tree (BST). It maintains a balance property where the difference in heights between the left and right subtrees of any node. [cite_start]If violates this property, the tree automatically performs rotations to restore balance[cite: 27].

**6. Red-Black Tree**
A **Red-Black Tree** is a self-balancing BST that uses a color attribute (red or black) for each node to ensure balance. [cite_start]It guarantees that the longest path from the root to a leaf is no more than twice as long as the shortest path[cite: 28].

**7. Max Heap**
A **Max Heap** is a complete binary tree that satisfies the heap property: the value of every parent node is **greater than or equal to** the values of its children. [cite_start]The largest element in the tree is always located at the root[cite: 29].

**8. Min Heap**
A **Min Heap** is a complete binary tree that satisfies the heap property: the value of every parent node is **less than or equal to** the values of its children. [cite_start]The smallest element in the tree is always located at the root[cite: 30].
