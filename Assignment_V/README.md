## 📖 Project Overview
This project is an exploration of various tree data structures, ranging from general trees to specialized self-balancing trees and heaps. The goal is to understand the hierarchy, constraints, and construction methods of each variant using a fixed set of integer data.

## 🔢 Input Data
The following 20 integers are used to construct every tree variant in this project:

## 🌲 Tree Variants Implemented
The report covers the definitions, hierarchy, and visualization of the following:

1.  **General Tree**: The most basic form of a tree.
2.  **Binary Tree**: A tree where each node has at most two children.
3.  **Complete Binary Tree**: A binary tree filled from top to bottom, left to right.
4.  **Binary Search Tree (BST)**: A binary tree with sorted property (Left < Root < Right).
5.  **AVL Tree**: A self-balancing BST (height difference ≤ 1).
6.  **Red-Black Tree**: A self-balancing BST using color properties.
7.  **Max Heap**: A complete binary tree where Parent ≥ Child.
8.  **Min Heap**: A complete binary tree where Parent ≤ Child.
